# Personas du projet

## 1) Développeur
**Rôle**
- Accède à la codebase
- Implémente, teste, maintient et améliore le projet

**Besoins**
- Architecture claire et documentée
- Règles de travail explicites
- Tests fiables pour sécuriser les évolutions

## 2) Admin
**Rôle**
- Met à jour les contenus du site sans modifier le code

**Actions principales**
- Modifier textes et visuels
- Gérer les événements
- Mettre à jour logo, galerie et médias du hero

**Besoins**
- Interface simple, rapide et sécurisée

## 3) Visiteur
**Rôle**
- Consulte le site du club

**Actions principales**
- Voir les prochains événements
- Consulter la galerie
- Envoyer une demande de réservation / privatisation
- Basculer la langue FR/EN

**Besoins**
- Navigation fluide mobile + desktop
- Informations claires et rassurantes
